SQL: stands for Structred Query Language: it's the standard domain language that used to manage and mainpulite data thatstored in realtion database

PL/SQL: stands for Procedural Language: it's oracle extension of SQL that add procedural elements such as conditon, loop, var, functions and store procedures. 


DDL: Data Defention language that define, alter and drop the structers of database objects
CREATE: build/view table
ALTER: modife structres 
DROP: delete table 
TRUNCTATE: empties rows

DML: Data Manipulate language: this manage and opreate on the actual data records within tables.
SELECT: retrive data
INSERT: add new rows
UPDATE: modefies data
DELETE: remove records

DCL: Data Control Language: used to control database access permission and security
GRANT: give privellage
PROVOKE: Take Privallge 





RDBMS VS. NoSQL Architecture: 

database management system dall into two major architectural families depending on data structre, scalability and consistency requirements. 


RDBMS (Relational) Feature: 
Structrued tabels with defined rows & colmuns, with predefined schema "DDL required upfront) and it have the ACID compliant (Atomicity, Consistency,  isolation and Durability) with Vertical Scalability to scale up with bigger CPU/RAM.

NoSQL (Non-Relation) Feature: 
Unstrucrted Database ( Documents, Key-Value, Graph, Column), with dynamic/schemaless, and it have BASE (Basically available, soft-state, Eventual consistency) with Horizontal it can scale out across mutliple servers).
